Build a gradient for Tailwind CSS v4

Use the visual generator to compare color stops, direction and interpolation, then inspect the result in your own page.

Choose the role of the gradient

Decide whether it is a decorative background or a surface behind content. Start with two colors and a simple linear direction. Add extra color stops only when they improve the transition rather than making the output harder to maintain.

Compare both outputs

The generator provides a CSS gradient and Tailwind CSS v4 output. Copy the format that matches your project. Confirm that the project actually uses Tailwind v4 before pasting version-specific utilities; a valid utility for one version may not be available in another.

Review with the real content

Place the headline and action over the gradient and check the least contrasting area. Try different viewport proportions because the colors behind the text can move as the element changes size. Keep a solid-color fallback where appropriate.
