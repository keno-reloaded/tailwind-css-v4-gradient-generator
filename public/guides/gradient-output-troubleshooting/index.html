Troubleshoot gradient direction and color output

Check version, interpolation and container size when the copied gradient differs from the preview.

The Tailwind class has no effect

Confirm the installed Tailwind version and build configuration. Try the CSS gradient output on the same element to distinguish a utility-generation problem from a layout problem. Ensure the element has visible dimensions.

The transition looks different

Compare the selected interpolation mode, color stop positions and direction. Different interpolation choices can produce visibly different middle colors even with the same endpoints. Check the destination browser and preserve the exported values when comparing results.

The composition changes on mobile

A gradient fills its container, so a wide banner and a tall card can place the same stops differently behind the content. Preview both aspect ratios and adjust the design for readability rather than trying to reproduce one fixed screenshot everywhere.
